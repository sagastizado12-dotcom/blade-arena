# Blade Realm: The Ten Winds
An open-world sandbox action RPG (iPhone PWA). You are a hero summoned by King Aldric. After that you're free to live however you like. The game grew out of the Blade Arena combat demo.
Play at https://sagastizado12-dotcom.github.io/blade-arena/ . Source is in `src/` and `./build.sh` builds `game.js`. Run tests with `npm i && npx playwright test`.
All art is original or derived from Monster Wilds art. There are no Nintendo assets.
